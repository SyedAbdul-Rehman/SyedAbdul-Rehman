<summary>⚙️ One-time setup for the stats card (do this once)</summary>

The stats/languages/activity card above needs a small GitHub Action to generate `metrics.svg` inside this repo. It replaces the old public widgets that were rate-limited and breaking.

1. In this repo (`SyedAbdul-Rehman/SyedAbdul-Rehman`), create the file `.github/workflows/metrics.yml` and paste in the workflow provided alongside this README.
2. Go to the **Actions** tab of this repo → select "Update Profile Metrics" → click **Run workflow** to trigger it the first time.
3. It commits `metrics.svg` to the repo root and refreshes itself daily after that. No secrets/tokens to add — it uses the repo's built-in `GITHUB_TOKEN`.

Dropped the trophy widget entirely — it lives on the same kind of shared free host that just broke, so it's one more thing that can silently go blank. Everything left in this README (streak card, self-hosted metrics, shields.io badges) comes from services that don't share that failure point.

</details>
